Real files. Honest status.

The current Phase 1 workspace focuses on document handling. It does not create legal analysis or sample records.

Upload and store

Upload PDF, DOCX, UTF-8 TXT, PNG, JPG, or TIFF files up to 50 MB. Files and document records are stored in your local workspace.

Validate and hash

File extension, signature, structure, and SHA-256 are checked and recorded. ClamAV scanning runs only when a scanner is configured.

Read and manage

View extracted PDF, DOCX, and TXT text, open supported files in the browser, download originals, archive, restore, or delete them.

Not enabled in this version

OCR, malware scanning without configured ClamAV, sensitive-data detection, LLM analysis, legal research, comparison, reports, and Google authentication.

Security & trust

Security status you can inspect.

Each uploaded record includes its checksum and the file checks that actually ran. Antivirus status is explicit, and analysis remains unavailable until implemented.
